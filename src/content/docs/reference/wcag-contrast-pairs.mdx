acss-kit validates 12 contrast pairs (`validate_theme.py:PAIRS`) against WCAG 2.2 AA requirements. All applicable pairs must pass before theme files are written; pairs where either role is absent in the theme file are silently skipped.

## The 12 pairs

### Text roles

<ColorSwatch roles={["text", "text-muted", "text-inverse"]} />

| Foreground             | Background           | Minimum | Category       |
| ---------------------- | -------------------- | ------- | -------------- |
| `--color-text`         | `--color-background` | 4.5:1   | Normal text    |
| `--color-text-muted`   | `--color-background` | 4.5:1   | Secondary text |
| `--color-text`         | `--color-surface`    | 4.5:1   | Text on card   |
| `--color-text-inverse` | `--color-primary`    | 4.5:1   | Text on brand  |

### Brand and interactive

<ColorSwatch roles={["primary", "focus-ring"]} />

| Foreground           | Background               | Minimum | Category                    |
| -------------------- | ------------------------ | ------- | --------------------------- |
| `--color-primary`    | `--color-background`     | 3.0:1   | Non-text interactive target |
| `--color-focus-ring` | `--color-background`     | 3.0:1   | WCAG 1.4.11 focus indicator |
| `--color-focus-ring` | `--color-surface`        | 3.0:1   | WCAG 1.4.11 focus indicator |
| `--color-focus-ring` | `--color-surface-raised` | 3.0:1   | WCAG 1.4.11 focus indicator |

### Semantic states

<ColorSwatch roles={["danger", "success", "warning", "info"]} />

| Foreground        | Background           | Minimum | Category           |
| ----------------- | -------------------- | ------- | ------------------ |
| `--color-danger`  | `--color-background` | 3.0:1   | Non-text indicator |
| `--color-success` | `--color-background` | 3.0:1   | Non-text indicator |
| `--color-info`    | `--color-background` | 3.0:1   | Non-text indicator |
| `--color-warning` | `--color-background` | 3.0:1   | Non-text indicator |

## WCAG thresholds

- **4.5:1** — normal text (< 18pt or < 14pt bold). Required for text, links, and UI labels.
- **3.0:1** — large text (≥ 18pt or ≥ 14pt bold) or non-text UI components. Used for interactive elements, focus indicators, and semantic state indicators.

## Testing manually

Use the browser DevTools color picker or a tool like [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) to verify ratios. Paste the `oklch()` or hex values for both colors.
